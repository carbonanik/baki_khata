# Baki Khata landing page

A Bengali-first, responsive static landing page for Baki Khata, using actual Flutter app screenshots supplied by the project owner.

## Preview

Open `index.html` in a browser, or run `python3 -m http.server 8000` in this folder and visit `http://localhost:8000`.

## GitHub Pages

Copy the contents of this folder to the branch/folder served by GitHub Pages (for example the repo root on `main`), then enable Pages under repository **Settings → Pages**.

## Downloads

The homepage links to the latest GitHub release APK and release notes for
`carbonanik/baki_khata`. The APK is available from GitHub Releases; the app is
not currently published on Google Play. Keep the release asset named
`app-release.apk` so the latest-download link continues to work.

Three provided screenshots had an Android "Screenshot captured" notification
overlay. The corresponding images were cropped to avoid showing that
notification. Replace these with clean, full-height captures when possible.

No build system required. Google Fonts are loaded when online; the page works with system fonts offline.
